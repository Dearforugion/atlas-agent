# Автоматизация в Windows

## Команды
- Обычные команды — через `run_shell` (это `cmd.exe`).
- PowerShell — только так: `powershell -NoProfile -Command "..."`.
- Сложные кавычки и многострочные сценарии лучше писать в `.ps1` файл и запускать его.
- Для расчётов, JSON, CSV, Excel и обработки текста используй `run_python`.

## Пути и кодировки
- Всегда работай относительными путями внутри рабочей папки.
- Пути с пробелами и кириллицей заключай в кавычки.
- Текстовые файлы сохраняй в UTF-8.
- Не полагайся на вывод консоли в OEM-кодировке: при сомнениях перечитай файл инструментом `read_file`.

## Безопасность
- Перед удалением или перезаписью проверь, что путь верный: `file_info`, затем `list_dir`.
- Не трогай системные папки, реестр, автозагрузку и планировщик без явной просьбы.
- Опасные команды требуют подтверждения — не пытайся обойти эту защиту.
- После изменения файла прочитай его или запусти проверку, чтобы убедиться в результате.
