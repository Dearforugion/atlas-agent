# Версия → CVE → эксплойт
Когда: разведка дала точные версии.
1) Зафиксируй версию (nmap -sV, whatweb, X-Powered-By). 2) Найди CVE: web_search/web_fetch (NVD, cve.org), shodan_host (готовые CVE по IP), google_dork «продукт версия exploit», searchsploit. 3) Оцени применимость: версия в диапазоне? компонент включён? 4) Эксплойт: metasploit_run или PoC. 5) Пруф: версия, CVE, модуль, результат. Не запускай вслепую без совпадения версий.
